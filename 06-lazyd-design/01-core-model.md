# 核心模型

> 区分可共享的数据与调用方的运行状态，使多个产品能够独立使用同一个 lazyd 服务。

| 对象 | 含义 | 身份与生命周期 |
| --- | --- | --- |
| 内容 | 确定的不可变字节对象及大小、格式、校验依据 | 内容身份不随镜像别名、VM 或凭据刷新改变；共享受安全域约束 |
| 来源 | 获取内容的位置和授权上下文 | 可刷新；鉴权按调用方和访问目标隔离 |
| 会话 | 一个调用方的使用上下文、预算与取消范围 | 有独立 owner；不等同于某个 Conch Sandbox |
| 使用绑定 | 会话对内容或映射区域的使用关系 | 持有期间保护资源；关闭不能误删其他会话使用的内容 |
| 共享任务 | 某内容范围的取数、检查与发布过程 | 多个等待者订阅结果；单个等待者取消不自动取消任务 |

这些是语义模型，不要求分别建表、创建进程或使用同名公开字段。对象 ID 的生成、幂等和存储格式在接口评审时确定。

## 一次通用请求

调用方准备内容描述与来源，建立使用会话；读取者请求内容范围。核心完成授权检查后，命中可用缓存或加入共享任务。完成结果描述实际可读范围与导出对象，适配层负责满足具体访问机制。

相同 digest 不授予访问权限。即使数据已在缓存，未授权会话仍不得导出；共享任务可以共享字节结果，但不能混用租户凭据。内容大小或格式冲突应拒绝。

## 独立性验收

不运行 Conch，用普通客户端准备内容、创建会话、读取范围和释放资源。验证两个调用方共享内容、取消隔离、权限拒绝、来源刷新和资源上限。UFFD 的独立联调再接兼容 VMM，不依赖 Conch 专有回调。

后续磁盘和内存快照须有明确的不可变来源视图与私有写入语义，不能仅增加一个类型标签就复用只读镜像行为。
